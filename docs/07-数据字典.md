# EvoCode 数据字典（字段级）

> 16 张表全部字段：类型 / 必填 / 默认 / 说明 / 示例
> 版本：v1.0 · 2026-08-10 · 与《开发指导》§5 DDL（V001-V007）一一对应

> 使用说明：实现实体类、DTO 映射、前端类型时的**查表工具**。字段"来源"列标注该字段由谁写入（用户/后端/analyzer/AI）。

---

## 1. 通用约定

| 项 | 约定 |
|---|---|
| 主键 | `BIGSERIAL` 自增，命名 `id` |
| 时间 | `TIMESTAMPTZ`；实体统一 `LocalDateTime`（UTC 存储，展示层转本地） |
| 逻辑删除 | 仅 `project` / `analysis` 含 `deleted SMALLINT DEFAULT 0`（MyBatis Plus 全局逻辑删除）；其余快照/明细表按 analysis_id 重建或随项目级联删除，无 deleted 列 |
| 枚举 | `VARCHAR(20)` 存短码，全大写；前端展示映射在组件层 |
| JSONB | MyBatis Plus 用 `JacksonTypeHandler` + `autoResultMap = true` |
| 命名 | snake_case 字段 ↔ camelCase 实体（map-underscore 开启） |
| 审计 | `created_at` 自动填充（MetaObjectHandler），`updated_at` 更新时间 |

## 6. 迁移与命名规则

- 新迁移：`db/migration/V0NN__desc.sql`，编号递增，**禁止修改已执行文件**（新增列走新版本）
- 新字段：snake_case；时间类以 `_at` 结尾；枚举类以状态语义命名（status/level/type）
- 删除字段：先停用（注释）一个版本，再删（单人项目可简化，但记录在变更日志）
- 字段口径变更（如健康分算法）必须同步：07 数据字典 + 06 契约 + 03 规范测试
