## 范围与验收

- `PATCH /projects/{id}`（重命名/描述）、`GET /projects/{id}/report/export`（Markdown 下载）、前端 ⋮ 操作菜单、TD-08 docgen 规则版降级。

## 实现

- **backend**：`ProjectUpdateReq`（name/description 可选）+ `ProjectService.update`（空白名/超长 1002、空请求 1001、不存在 2001）；`ReportExportService` 纯字符串 Markdown（健康评分/维度表/风险项/建议，无模板引擎）；`GET /projects/{id}/report/export` → `text/markdown` + Content-Disposition。
- **TD-08（analyzer）**：`docgen.generate_doc` 无 Key 或 LLM 失败 → `_rules_doc` 模板降级（README/ARCH/API 三模板，`source=RULES`）；`DocResponse.source` 透传；路由不再抛 400 LLM_NO_KEY（无 Key 也 200）。
- **backend 透传**：`AnalyzerClient.DocResp`/`DocResp` 加 `source`（不落库，避免迁移）。
- **frontend**：⋮ 操作菜单（重命名/导出报告/删除）+ 重命名弹窗（名称/描述，前端必填校验）+ `exportReport` blob 下载（空 blob 提示无报告）+ `updateProject` PATCH；外部点击关菜单；`ProjectSummary` 补 `description`。

## 验证

- backend 128/128（含 PATCH 校验 5 例、导出 3 例、doc source 透传）；analyzer 全量 + ruff 全绿（docgen 规则降级 6 用例）；frontend lint（0 error）+ build + vitest 12/12。

## 踩坑

- `mvnw` 在 PowerShell 下测试全绿仍报非零退出码（stderr 流误判），以 `Tests run:` 行核对。
- `ProjectResp` 原缺 `description` 字段；`Set-Content -Encoding UTF8` 会写 BOM 破坏 javac（用无 BOM 写入）。
- 主按钮类名是 `.btn-primary`（非 `.btn.primary`）。

## 遗留

- 导出无报告时返回空 blob（前端提示）；LLM 成功/规则版由 `source` 字段区分，前端暂未展示徽标。
