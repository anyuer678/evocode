## 交付内容（docs/06-API契约.md §5.3）

- `analyzer/app/core/sonar.py`：**SonarClient**
  - `available()`：token 已配置 + host 可达（GET /api/system/status）+ sonar-scanner 可执行，**三者缺一即降级 N/A**（AD-8/R7：不可用不影响其他维度）
  - `scan()`：scanner 执行（`sonar.projectKey=evocode-{id}`、排除构建产物/依赖目录、scm 禁用）→ CE 任务轮询（最长 120s）→ `/api/measures/component` 指标拉取（bugs/vulnerabilities/code_smells/duplicated_lines_density/coverage/complexity）→ `/api/issues/search` issues 归一（ruleKey/severity/kind/filePath/line/message）
  - 任一步失败 → 返回 None（HTTP 仍 200）
- `analyzer/app/config.py`：+ sonar 配置族（host/token/scanner/timeout/CE 轮询）
- `analyzer/app/schemas.py`：QualityMetrics（available 字段 + 可空指标）/ QualityIssue / QualityRequest / QualityResult
- `analyzer/app/main.py`：`POST /analyze/v1/quality`
- `analyzer/tests/test_quality.py`（7 例）：无 token/无 scanner/host 不可达降级、全流程指标与 issues 解析（mock httpx + subprocess）、scanner 失败降级、端点不可用/可用
