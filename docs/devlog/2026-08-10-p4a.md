## 踩坑记录

1. **跨文件匹配**：初版边匹配在单文件内做，分层样例（三类分三文件）匹配不到。重构：parser 返回调用候选（caller_key → 候选名列表），archscan 在全局节点集合上统一匹配。
2. **`n not in node_keys` 逻辑写反**：本意排除自调用，实际把"调用名恰为节点名"的正常调用全部跳过。改为 `target != caller` 排除自环。
3. **Java 注入风格调用**：`service.getUser()` 的 object 是变量名，静态类型不可知。加字段类型映射（field_declaration 收集 `field名→类型`）后 Spring 风格注入场景可解析。
4. **curl 传中文路径**（工作区"烧token"）：JSON 经 Windows 控制台编码损坏 → codeDir 失效返回空。非项目 bug，联调用无中文临时路径。顺带发现 `codeDir=""` 会退化为扫描当前目录（仅 127.0.0.1 内部使用，可接受，记录在案）。
