## 交付内容

### 前端

- `types/api.ts`：分析/报告类型族——`AnalysisStatus`（轮询）、`AnalysisCreated`（202）、`ReportDetail` + `HealthReport`（healthScore/level/techStack/dimensions/risks/recommendations/scoreDetail）
- `api/analysis.ts`：createAnalysis / listAnalyses / getAnalysisStatus / getReport / regenerateReport
- `views/project-detail/index.vue`（重构）：
  - **体检报告区**：健康分大字 + level 徽章（优秀/良好/一般/较差）+ 来源徽章（AI 报告/规则报告）+ promptVersion/时间；summary；4 维度星级卡片（质量/结构/依赖/规模）；风险列表（HIGH/MEDIUM/LOW 色标 + 建议）；演化建议（阶段分组）
  - **分析操作**：发起完整分析按钮（→202→2s 轮询→完成自动刷新）；重新生成报告按钮（regenerate，2008 排他提示透传）
  - **分析历史**：表格（状态/进度/健康分/来源/时间），点击切换对应报告，运行中项自动续轮询
  - 保留档案区与文件地图；自动快扫轮询沿用
- `vite.config.ts`：proxy target 支持 `VITE_PROXY_TARGET` 环境变量覆盖（本机 8080 被 polycode 占用时可指向其他端口，长期有效）

## 实库联调验证（前端 proxy 路径）

## 踩坑/改进记录

1. **`@click="filePage--; loadFiles()"` 多语句会被 prettier 拆行导致 Vue 模板编译错误**（上轮踩过、本轮重写时又出现）——统一改为 `prevFilePage/nextFilePage` 方法。规范：**模板事件处理器只写单方法调用**。
2. vite proxy 写死 8080：本机与 backend 实际端口不符时 404。改为环境变量可覆盖，默认值不变。
